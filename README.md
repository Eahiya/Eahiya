## 🏆 Headline Project: F1 Optimal Pit Strategy Predictor

<div align="center">

[![Open the live platform](https://img.shields.io/badge/▶%20OPEN%20THE%20LIVE%20PLATFORM-FF3D81?style=for-the-badge&logo=vercel&logoColor=white)](https://f1-strategy-platform.vercel.app/login)

</div>

An AI-powered Formula 1 strategy platform for **real-time race simulation and pit-stop optimisation**. It takes the race state, runs it through a machine-learning model, and recommends when to pit.

📖 **[Read how it works: the full write-up](https://github.com/Eahiya/Eahiya/blob/main/F1-STRATEGY.md)**

```mermaid
flowchart LR
    A[🏁 Race State<br/>lap, tyres, gaps] --> B[⚛️ React Dashboard]
    B --> C[⚡ FastAPI Backend]
    C --> D[🧠 ML Strategy Model]
    D --> E[📊 Pit Window and Compound Recommendation]
    E --> B
```
